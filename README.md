# A S Udaya K R G — Physics Portfolio

Responsive scientific academic portfolio built with HTML, CSS and vanilla JavaScript for GitHub Pages.

## Files
- `index.html` — website content
- `css/style.css` — design, responsive layout and CSS animations
- `js/script.js` — mobile navigation, scroll progress, reveal and active navigation
- `assets/atom.svg` — favicon

## Preview
Extract the ZIP and open `index.html` in a browser. For easier editing, open the folder in Visual Studio Code.

## Personalise before publishing
In `index.html`, replace:
- `Add your university` with your institution.
- Sample PhD research text with your real research title and summary.
- `your.email@example.com` with your professional email.
- Generic LinkedIn and Google Scholar links with your actual profile URLs.
- Add verified publications, conference presentations, projects and dates only.
- The initials avatar can be replaced with your own photo. Put it in `assets/` and replace the `.profile-art` content with an `<img>`.

## Publish on GitHub Pages
1. Sign in to your own GitHub account or create one at https://github.com/.
2. Create a **public** repository named exactly `YOUR-USERNAME.github.io` (replace with your GitHub username).
3. Extract this ZIP. Upload the *contents* of the `udaya_physics_portfolio` folder so `index.html` is in the repository root.
4. Commit to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch `main` and folder `/ (root)`, then Save.
8. Wait for deployment. Your website URL will be `https://YOUR-USERNAME.github.io/`.

No paid hosting, backend or build process is required. Google Fonts need an internet connection; fallback fonts are included.
